# Leak Tracking

Мобильное приложение для отслеживания утечек воды на объектах. Позволяет фиксировать, редактировать и экспортировать данные об утечках с привязкой к геолокации и фотографиям.

## Возможности

- 📍 **Геолокация** — автоматическое определение координат при создании утечки
- 📸 **Фотографии** — съёмка и хранение фото с возможностью сжатия
- 🗺️ **Карта** — визуализация утечек на интерактивной карте
- 🎤 **Голосовой ввод** — распознавание речи для быстрого заполнения форм
- 📊 **Экспорт** — выгрузка данных в Excel/CSV
- 🔄 **Офлайн режим** — работа без интернета с локальным хранилищем
- 📱 **Capacitor** — нативная сборка для Android

## Технологии

- **React 19** — UI фреймворк
- **Vite** — сборщик
- **Capacitor 8** — нативный слой
- **Leaflet** — карты
- **Zod** — валидация
- **IndexedDB** — локальное хранилище

## Установка

```bash
npm install
```

## Команды

| Команда | Описание |
|---------|----------|
| `npm run dev` | Запуск dev-сервера |
| `npm run build` | Сборка production |
| `npm run cap:sync` | Синхронизация с Android |
| `npm run test` | Запуск тестов |

## Android

```bash
# Синхронизация
npx cap sync

# Открытие в Android Studio
npx cap open android
```
