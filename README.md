# Leak Tracking

Приложение для учёта, анализа и визуализации утечек газа.

Система рассчитана на работу в полевых условиях и поддерживает сценарии эксплуатации, мониторинга и MRV-процессов.

---

## Назначение

Проект помогает:

- фиксировать утечки на объекте
- привязывать их к карте и координатам
- вести статусы и историю изменений
- оценивать данные для последующей отчётности
- экспортировать результаты в удобные форматы

---

## Основные возможности

### Работа с утечками
- создание новой записи
- просмотр и редактирование карточки
- хранение фото и комментариев
- ведение статуса устранения
- групповая смена статуса

### Сбор данных
- геолокация через Capacitor
- фотофиксация через камеру
- голосовой ввод
- ручное заполнение формы

### Аналитика и визуализация
- отображение утечек на карте (Leaflet)
- кластеризация маркеров
- поиск и фильтрация по базе
- цветовая и статусная индикация

### Карта
- интерактивная карта с кластеризацией маркеров
- поддержка офлайн-карты с кэшированием тайлов

### Экспорт
- экспорт в XLSX (ExcelJS)
- экспорт в KML
- резервная копия данных (JSON-backup)

---

## Поддерживаемые типы проектов

В приложении используются 3 конфигурации:

- **Upstream** — добыча
- **Midstream** — транспортировка и хранение
- **Downstream** — переработка и сбыт

Для каждого типа проекта могут отличаться:
- поля формы
- справочники
- логика поиска
- шаблоны экспорта

---

## Экранная структура

- **ProjectSetup** — первичная настройка проекта
- **MainPage** — главная страница с быстрыми действиями и последними записями
- **AddLeak** — добавление утечки
- **MapPage** — карта утечек
- **DataBase** — список и база данных
- **Settings** — настройки проекта и справочников

---

## Статусы утечки

Используется последовательный жизненный цикл:

- `open` — открыта
- `in_progress` — в работе
- `resolved` — устранена

Переходы между статусами выполняются по логике приложения, без пропуска этапов.

---

## Хранение данных

Проект может работать без backend.

### Web-версия
Данные сохраняются в `localStorage`.

### Мобильная версия
Данные сохраняются в файловой системе приложения через Capacitor.

Типичный путь хранения:

```text
LeakReports/{folderName}/data/data.json
```

Фото сохраняются локально в приватном хранилище приложения.
