# Leak Tracking System

Система для регистрации, анализа и управления утечками газа  
(эксплуатация + MRV-процессы).

---

## 🎯 Назначение

Приложение решает 4 задачи:

1. Фиксация утечек (LDAR)
2. Оценка потерь газа и метана
3. Приоритизация ремонтов (экономика / риск)
4. Формирование отчетности

---

## ⚙️ Функционал

**Сбор данных**
- Геолокация (Capacitor)
- Фото (Camera API)
- Голосовой ввод

**Аналитика**
- Оценка потерь газа
- Расчет приоритетов
- Статусы: Active / Deferred / Fixed

**Визуализация**
- Карта (Google Maps)
- Кластеризация утечек

**Работа с данными**
- Редактирование (LeakDetailsSheet)
- Экспорт в Excel
- Локальное хранение

## 📊 Модель данных (Leak)

- ID
- координаты
- тип оборудования
- источник утечки
- уровень
- статус
- фото / комментарии

---

## 🧠 Логика приоритизации

Решение об устранении:

- объем потерь газа
- стоимость потерь
- влияние на производство
- необходимость остановки

Если ремонт нерентабелен → **Deferred**
