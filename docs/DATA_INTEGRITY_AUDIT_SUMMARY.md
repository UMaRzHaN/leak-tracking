## Коротко

Проверены все пути, которыми запись об утечке, карточка реестра или фотография
могут пропасть, откатиться или разойтись между копиями: веб-хранилище
(IndexedDB, зеркало, `localStorage`), Android (SQLite, маркеры переезда,
резервное копирование ОС), фотографии и их уборка, импорт/слияние/откат ZIP,
черновики, синхронизация.

Веб-часть изначально сделана бережно (две копии с контрольными суммами,
ревизии, откат импорта). Основные риски были на Android: все проекты лежат в
одном файле SQLite без второй копии.

**Итог:** исправлено 7 дефектов, добавлено 3 защиты на уровне продукта,
4 пункта сознательно оставлены с обоснованием.

## Исправленные дефекты

| #   | Серьёзность  | Что было                                                                                                           | Что стало                                                                                                                        |
| --- | ------------ | ------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 🔴 Критичная | При любой порче файла SQLite Android по умолчанию **удалял базу целиком** — все проекты устройства.                | Файл и журнал копируются рядом (`leak_tracking.db.corrupt-<время>`), оригинал не удаляется, приложение показывает ошибку чтения. |
| 2   | 🟠 Высокая   | Проект, переехавший в SQLite, но пропавший из базы, молча открывался пустым или из старого JSON (откат на месяцы). | Ошибка `SQLITE_PROJECT_MISSING`, запись блокируется — остатки не затираются.                                                     |
| 3   | 🟠 Высокая   | Если реестр компонентов не прочитался, одна новая карточка сохранялась **вместо всего обхода**.                    | Запись строится только на прочитанном списке; ошибка чтения — отказ записи.                                                      |
| 4   | 🟡 Средняя   | Фоновая уборка могла удалить только что снятое фото до сохранения карточки.                                        | Фоновая уборка не трогает снимки моложе суток.                                                                                   |
| 5   | 🟡 Средняя   | Подтверждённая запись в SQLite могла пропасть при отключении питания (`synchronous=NORMAL`).                       | `PRAGMA synchronous=FULL`.                                                                                                       |
| 6   | 🟡 Средняя   | Реестр компонентов на Android без маркера переезда — та же проблема, что в п. 2.                                   | Свой маркер `components.sqlite.json` и те же проверки.                                                                           |
| 7   | 🟢 Низкая    | Черновик жил 24 ч; если фото не влезало в квоту — терялся весь черновик с текстом.                                 | Срок — неделя; при нехватке квоты сохраняется без фото.                                                                          |

## Добавленные защиты

| #   | Что                       | Как работает                                                                                                                                                        |
| --- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 8   | Напоминание о бэкапе      | В настройках — дата последнего ZIP-экспорта. На главной — баннер, если данные проекта больше 7 дней только на этом устройстве. «Позже» — до перезапуска приложения. |
| 9   | Статус хранилища браузера | В настройках видно, может ли браузер сам стереть данные сайта; если может — предупреждение.                                                                         |
| 10  | Копия списка проектов     | Список дублируется вне `localStorage` (IndexedDB в вебе, файл на телефоне). Если ключ пропал — список восстанавливается при запуске.                                |

## Сознательно не сделано

| Что                                                | Почему                                                                                                                                                                                               |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Автобэкап по расписанию                            | Архив с фото — сотни МБ; тихая выгрузка на полном телефоне сама может привести к «нет места» при сохранении утечки. Если нужен — только по явному включению, с проверкой места и ротацией 2–3 копий. |
| Поиск «потерянных» проектов по ключам хранилищ     | По ключу не восстановить имя и тип; задачу решает копия списка (п. 10).                                                                                                                              |
| Миграции SQLite / откат версии                     | Сейчас при откате схемы база не открывается, но и не трогается — безопасный отказ. Перед первым подъёмом `DATABASE_VERSION` нужна миграция с тестом.                                                 |
| Автоперечитывание проекта между вкладками браузера | Опасно: форма на старых данных затёрла бы чужие правки. Сейчас такая запись отклоняется.                                                                                                             |
