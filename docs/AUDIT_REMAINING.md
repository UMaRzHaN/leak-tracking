## 2. Проверить на телефоне

В ветке `claude/audit-3itf9h` изменён `file_paths.xml` — корни FileProvider.
Android SDK в среде аудита не было, поэтому сборка не запускалась.

Собрать установочную копию релиза: `npm run android:check`.

- [ ] **PDF-схема.** Реестр компонентов → схемы → нажать на PDF-схему.
      Ожидается выбор приложения и открытый файл. До исправления — ошибка
      «На устройстве нет приложения, которое откроет схему». Схемы-картинки
      открываются внутри приложения и правкой не затронуты.
- [ ] **Фото с камеры.** Новая утечка → фото → снять. Снимок появляется в
      форме и сохраняется вместе с записью.

Если камера после правки сломалась, ошибка будет вида `Failed to find
configured root that contains …`. Путь из неё показывает, какой корень нужно
вернуть в `android/app/src/main/res/xml/file_paths.xml` — точечно, а не
`<external-path path=".">` целиком.

## 3. Ограничить ключ Google Map Tiles

`VITE_GOOGLE_MAPS_KEY` попадает в собранное приложение — это неизбежно для
клиентского API, и любой, кто распакует APK или откроет веб-сборку, ключ
увидит. Защита — ограничения на стороне Google.

Google Cloud Console → APIs & Services → Credentials → ключ:

- [ ] **API restrictions:** только Map Tiles API.
- [ ] **Квота:** IAM & Admin → Quotas → Map Tiles API — дневной лимит
      запросов с запасом над реальным расходом.
- [ ] **Application restrictions → HTTP referrers**, отдельный ключ на
      каждую сборку (ограничение одного типа на ключ):
  - Android: `https://localhost/*`. Тайлы запрашивает WebView, а не Google
    SDK, поэтому ограничение «Android apps» здесь не подходит: заголовков с
    пакетом и сертификатом в запросе нет, и карта перестанет грузить снимки.
    Referrer `https://localhost` у Capacitor по умолчанию; если в
    `capacitor.config.ts` появятся `server.hostname` или `androidScheme` —
    поменять и здесь.
  - веб: адрес, где опубликована сборка, с учётом `VITE_BASE_PATH`.

  Referrer подделывается вне браузера, так что это защита от использования
  ключа на чужих сайтах, а не от скриптов. От скриптов — квота выше и алерт ниже.

- [ ] **Budget alert** в Billing — чтобы утечка ключа была видна по счёту
      сразу, а не в конце месяца.

## 4. Бюджет сопровождаемости — до CI, а не в CI

Лимиты размера файлов нарушаются при каждой крупной фиче, и узнаётся об этом
только из CI. После слияния PR #25 (до него хук блокировал бы любой push):

- [ ] Создать `.husky/pre-push`:

  ```sh
  npm run check:maintainability
  ```

Проверка занимает секунды. Если файл вырос законно — поднять ему исключение в
`scripts/maintainability-budget.json` в том же коммите, где он вырос.
