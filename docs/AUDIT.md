## Что сделано

- **Данные.** Уборка фото больше не удаляет снимки сверки компонентов. Журнал
  IndexedDB не ложится на чужую основу после отказа одной из копий. Реестр не
  затирается записью до окончания чтения и записью из второй вкладки.
  Десятичная запятая в карточке компонента не обнуляется.
- **Обмен.** Слияние ZIP узнаёт утечку по `id`, если у неё поправили номер.
  «Объединить» и Excel-копия переносят накладные и обследование, откат
  импорта их возвращает. Слияние Excel не склеивает утечки с одним номером.
  `id` чертежа из чужого архива не становится путём к файлу. Каждый ZIP
  проходит предпроверку числа записей до разбора.
- **Экраны.** Правка записи не сохраняет новые замеры рядом со старыми
  выбросами. Номер бирки в карточке проверяется на дубль. Массовые действия
  в «Базе» и реестре — только по видимым выбранным. Аналитика ремонтов не
  считает брошенные ремонты «в работе». «К сверке» в меню не показывает 0.
- **Голос и карта.** Команда срабатывает только на фразу целиком. Подбор
  значения требует совпадения большинства слов, лист подтверждения показывает
  сказанное. Снимок в карточке булавки открывается во весь экран.
- **Android.** Повторный экспорт не удаляет прошлый бэкап раньше, чем записан
  новый. Сеанс синхронизации гаснет на экране после лимита неверных кодов и
  после 5 сбоев приёма подряд. Сервер синхронизации слушает только локальный
  адрес.
- **Сборка.** CI снова запускается (был повторён ключ `concurrency`).
  Релиз сверяет отпечаток сертификата подписи и сохраняет `mapping.txt`.
  Gradle wrapper проверяется по контрольной сумме.

## Оставшиеся задачи

### Проверить на телефоне

Юнит- и e2e-тесты этого не покрывают: нужен реальный Android и MediaStore.

- [ ] **Повторный экспорт ZIP.** Файл заменяется и остаётся под именем
      `<проект>.zip`, в `Documents` не остаётся `export-…zip`.
- [ ] **Синхронизация, неверный код.** После 5 неверных кодов QR на экране
      гаснет и показывается сообщение.
- [ ] **Синхронизация, сети.** Обмен работает по Wi-Fi и когда телефон
      раздаёт точку доступа. По возможности — с включённым VPN.
- [ ] **Обмен ZIP между двумя телефонами** с накладными и обследованием:
      после «Объединить» они есть на обоих.
- [ ] **Голосовой ввод.** Короткая диктовка с «очистить» или «готово» внутри
      фразы не стирает и не сохраняет форму; подстановки из списка верные.
- [ ] **Камера.** Отмена съёмки не показывает ошибку.
- [ ] **Карта.** У записи «В ремонте» в карточке булавки есть снимок, и он
      открывается во весь экран.
